# 📝 Keeper App

A minimalist note-taking web app built with **React** and **Vite**. Inspired by Google Keep, it allows users to create and delete notes with a clean, responsive interface.

---

## 🔗 Live Demo

[View it on GitHub Pages](https://samuel-faith.github.io/keeper-app/)

---

## ⚙️ Features

- Add and delete notes
- Responsive layout
- Built with React 17 + Vite
- Unique note IDs using `uuid`
